# Direção visual

## Laboratório 404

O laboratório deve parecer um lugar que realmente funcionava antes do jogador chegar.

### Camadas
1. arquitetura industrial;
2. instrumentação;
3. manutenção;
4. sinais de falha;
5. presença de ARIA.

## Regra visual

Sempre que possível, cada sala deve possuir:
- um elemento alto;
- um elemento luminoso;
- um elemento móvel;
- um ponto de interação;
- um elemento narrativo.
