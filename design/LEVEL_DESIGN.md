# Level Design — mapa do POC 6

```text
                    ┌──────────────┐
                    │  SALA ARQUIVO│
                    │      ★       │
                    └──────┬───────┘
                           │
┌──────────────┐     ┌─────┴───────┐
│ SALA BOMBAS  │─────│ CORREDOR    │─────┌──────────────┐
│      ★       │     │      ●      │     │ CONTROLE     │
└──────────────┘     └─────┬───────┘     │ ARIA ★      │
                           │              └──────┬───────┘
                    ┌──────┴───────┐             │
                    │ ENERGIA      │─────────────┘
                    │      ★       │
                    └──────────────┘
```

★ = ponto de interesse
● = rota principal

## Princípios

O jogador deve sempre saber:
- onde está;
- qual é o objetivo;
- qual interação é possível;
- qual pista recebeu.

Mas não deve saber necessariamente **por que ARIA quer determinada ação**.
